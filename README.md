# Bloom Within

An animated, gentle help-and-resources site for people affected by eating disorders.

Plain HTML, CSS and JavaScript — no build step. Open `index.html` or host it with GitHub Pages.

- `index.html` — page content
- `style.css` — design and animations
- `script.js` — interactions (particles, breathing, grounding, helplines, draggable notes)

Helpline numbers live in `script.js` under `helplines` — re-check them every few months.
